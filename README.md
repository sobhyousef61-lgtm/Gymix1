# GYMIX — Your Gym. Under Control.

نظام إدارة النوادي الرياضية في سوريا.

## الحالة
- المرحلة 1: بنية المشروع + التصميم + الصفحة الرئيسية ✅ (لم تُختبر بعد، انظر الملاحظات)
- المرحلة 2: قاعدة البيانات وتسجيل الدخول ⏳

## التقنيات
Next.js 15 (App Router) · React 19 · TypeScript · Tailwind CSS 3.4 · Supabase · Vercel

## الملفات
- app/layout.tsx : الاتجاه RTL وخط Cairo
- app/page.tsx : الصفحة الرئيسية العامة
- app/globals.css : الأزرار والألوان
- components/ : الشعار، الهيدر، الفوتر
- .env.example : قائمة المتغيرات البيئية
